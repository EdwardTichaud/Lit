# Travaux AIAgent

Utiliser ce dossier pour conserver les travaux utiles : notes de recherche,
prompts prepares, sorties synthetiques ou comptes rendus qui peuvent aider plus
tard.

Regles :

- Creer un sous-dossier par sujet ou par date quand un travail devient
  volumineux.
- Ne pas stocker de secrets, `.env`, environnements virtuels, caches ou sorties
  Unity generees.
- Placer les connaissances durables dans `../Codex/systems/`, pas ici.
- Garder `../Codex/current_work.md` reserve au contexte actif, pas a
  l'historique.
