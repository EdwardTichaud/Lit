## Prompt Codex

```text
Objectif
Comprendre puis corriger pourquoi, dans le couloir du district 1, tout le couloir semble être détecté comme un obstacle franchissable, ce qui déclenche l’animation de franchissement d’obstacle en boucle. Je veux une cause probable appuyée par le code et un patch minimal.

Contexte
Le système de franchissement automatique d’obstacles est documenté dans `systems/input_camera_ucc.md` et semble centralisé dans `LitOpsiveLocomotionBridge`. La doc précise :
- les petits obstacles sous un seuil sont ignorés ;
- les obstacles bas franchissables déclenchent un traversal scripté ;
- les surfaces progressives/pentes doivent être ignorées via `obstacleTraversalMaxSurfaceUpDot` pour éviter qu’une pente/colline/tas de terre déclenche l’animation.
Le symptôme “tout le couloir est un obstacle” suggère un problème de détection continue : normals mal filtrées, layer mask trop large, self-hit, trigger, collider de décor du couloir interprété comme face abrupte, ou retrigger pendant un traversal déjà en cours.

Avant toute modification
1. Lire `AIStudio/docs/AGENTS.md`.
2. Lire ensuite uniquement ces documents :
   - `AIStudio/docs/architecture.md`

- Préserver les changements Git existants.

   - si le filtre sur la normale de surface est insuffisant ou inversé ;
   - si des triggers / colliders du personnage / colliders enfants peuvent être détectés à tort ;
   - si le système peut retrigger tant qu’un traversal est en cours ou juste après ;
   - si une distance de sonde ou un point d’origine de cast provoque un hit permanent dans un espace étroit.
3. Corriger avec le patch minimal le plus local possible.
4. Expliquer brièvement la cause retenue et pourquoi le correctif est sûr.
5. Ne pas modifier d’autres systèmes si une garde locale suffit.

Stratégie proposée
- Lire d’abord `LitOpsiveLocomotionBridge.ObstacleTraversal.cs`.

  - conditions d’entrée ;
  - cast/overlap utilisé ;
  - critères d’acceptation d’un obstacle ;
  - garde anti-retrigger éventuelle.
- Si le bug vient d’une mauvaise qualification des surfaces du décor :
  - renforcer le filtre local sur hit/normale/hauteur/profondeur sans changer l’architecture.
- Si le bug vient d’un retrigger :
```
